# web

쇼츠 MVP의 웹 화면입니다. 빌드 단계와 외부 의존성이 없는 정적 사이트(HTML, CSS, ES 모듈)이며, `web/` 폴더를 그대로 웹 버킷에 올립니다. 화면은 같은 출처의 `/api`를 호출하고, API 형식은 [docs/plans/2026-11-27-mvp-backend-contract.md](../docs/plans/2026-11-27-mvp-backend-contract.md)의 3절을 따릅니다. 모든 화면 문구는 한국어입니다.

## 화면 구성

단일 페이지이며 주소의 해시로 화면을 나눕니다. API가 401을 돌려주면 어느 화면에서든 로그인 화면으로 바뀝니다.

- 로그인(`#/`, 로그아웃 상태): `GitHub로 로그인` 링크가 `/api/auth/login`으로 이동합니다. 주소에 `?error=not_member`가 있으면 `awskrug` 조직의 `sns-working-group` 팀 멤버만 로그인할 수 있다고 안내합니다.
- 작업 목록(`#/`): 제목, 파일 이름, 상태, 만든 사람, 만든 시각을 보여 주며, 최종 상태(분석 완료, 실패)가 아닌 작업이 있으면 5초마다 새로 불러옵니다.
- 새 작업(`#/new`): 영상 파일과 선택 사항인 이름을 받습니다. 5 GiB를 넘는 파일은 API를 부르기 전에 거절합니다. 작업을 만들고, `XMLHttpRequest`로 업로드 주소에 `PUT` 하며 진행률(백분율과 MB)을 보여 주고, 분석을 시작한 뒤 작업 화면으로 이동합니다. 업로드가 실패하면 같은 작업으로 다시 올리는 버튼이 나옵니다.
- 작업 화면(`#/jobs/{jobId}`): 분석이 끝나기까지 5초마다 상태를 새로 불러옵니다. 분석이 끝나면 구간 후보를 보여 주고, 후보를 고르면 영역 편집기가 열립니다.
- 영역 편집기: 후보 구간만 재생하는 영상 위에서 `발표 화면`(파랑, 실선)과 `발표자`(주황, 점선) 사각형을 끌어서 옮기고 모서리를 끌어서 크기를 바꿉니다. 사각형에 초점을 두고 방향키로 옮기고, Shift와 방향키로 크기를 바꿀 수도 있습니다. 화면 좌표는 영상의 레터박스를 고려해 원본 픽셀 정수 `[x, y, w, h]`로 바꿔 보냅니다. `영역 없이 렌더링` 확인란을 켜면 두 영역을 모두 `null`로 보냅니다.
- 렌더링 결과: 최신순으로 구간 제목, 상태, 완료된 경우 세 구성(split, blur, crop)의 세로 영상과 내려받기 링크를 보여 줍니다. 렌더링 중인 항목이 있으면 5초마다 새로 불러옵니다.

서버가 준 문자열은 `textContent`와 DOM API로만 넣으므로 HTML로 해석되지 않습니다.

## 코드 위치

| 경로 | 내용 |
|---|---|
| `index.html`, `styles.css` | 진입 페이지와 스타일(밝은 테마와 어두운 테마) |
| `js/app.js` | 해시 라우팅, 머리글(사용자와 로그아웃) |
| `js/api.js` | `fetch` 래퍼. 오류 본문의 `error` 문구를 그대로 보여 줍니다 |
| `js/geometry.js` | 화면과 원본 좌표 변환, 레터박스, 범위 제한, 최소 크기, `mm:ss` 형식 |
| `js/status.js` | 상태 문구, 5 GiB 검사, 진행률 문구 |
| `js/views/` | 화면별 코드 |

## 테스트

Node 내장 테스트 실행기를 쓰며 설치할 패키지는 없습니다. 순수 함수와 API 래퍼를 검사합니다.

```bash
cd web
npm test
```

## 백엔드 없이 화면 시험하기

`dev/mock-server.mjs`가 `web/`을 내주고 `/api`를 메모리에서 흉내 냅니다. 처음부터 분석이 끝난 예시 작업과 완료된 렌더링이 하나씩 들어 있고, 새 작업을 만들면 몇 초 안에 상태가 차례로 바뀝니다.

```bash
cd web
node dev/mock-server.mjs        # 기본 http://127.0.0.1:8787/ , PORT=0 이면 빈 포트
```

`http://127.0.0.1:8787/`을 열고 `GitHub로 로그인`을 누르면 로그인된 상태가 됩니다. `/api/auth/login?deny=1`을 열면 `not_member` 안내를 볼 수 있습니다. 영상 주소는 `/dev-sample/`을 가리키며, 실제 영상을 보려면 `web/dev/sample/`에 `source.mp4`, `split.mp4`, `blur.mp4`, `crop.mp4`를 직접 넣습니다. 파일이 없으면 영상 칸만 비어 있습니다.

`web/` 폴더 전체가 공개 웹 버킷에 올라가므로 `dev/`와 `tests/`도 함께 올라갑니다. 이 폴더들에는 비밀 값이 없고 크기가 작아 지금은 그대로 둡니다. `dev/sample/`에 큰 영상을 넣었다면 배포 전에 지우세요.
