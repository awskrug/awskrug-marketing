# web

운영진이 쓰는 웹 화면이 들어갈 자리입니다. 아직 코드는 없습니다.

이 화면에서 운영진은 녹화 영상과 슬라이드 파일을 올리고, 작업 진행 상태를 보고, 자동으로 추정한 슬라이드 전환 시점을 고치고, 완성된 영상을 내려받습니다. 이 화면은 GitHub 계정으로 로그인하며, GitHub `awskrug` 조직의 `sns-working-group` 팀 멤버만 사용할 수 있습니다. 주소는 `marketing.awskr.org`로 정했습니다. 로그인 방식은 [docs/architecture.md](../docs/architecture.md)의 "인증과 사용자 범위"에 있습니다.
