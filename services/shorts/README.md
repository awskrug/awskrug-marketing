# shorts

쇼츠를 만드는 처리 코드가 들어갈 자리입니다. 아직 코드는 없습니다.

이 서비스는 녹화 영상의 전사 텍스트에서 핵심 구간을 고르고, 그 구간을 잘라 자막을 입힌 세로(9:16) 영상을 만듭니다. 처리 단계는 핵심 구간 선정과 FFmpeg 렌더링의 두 가지입니다. 설계는 [docs/architecture.md](../../docs/architecture.md)에, 렌더링 구현에 참고할 외부 프로젝트 검토 결과는 [docs/reference-kshorts-studio.md](../../docs/reference-kshorts-studio.md)에 있습니다.
